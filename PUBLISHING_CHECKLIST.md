# Before publishing

This archive updates project documentation using the pipeline handbook. Before treating the repository as a fully reproducible analysis, verify that the public repository includes the actual scripts and outputs referenced by the documentation.

Recommended checks:
- Confirm the accession list and metadata against the NCBI BioProject record.
- Add the actual scripts and software/database versions used.
- Add real plots/tables generated by the workflow; do not create figures that are not from the analysis.
- Confirm exact methods and statistical test settings from output files/scripts.
- Keep raw FASTQ and large QIIME 2 artifacts out of GitHub unless there is a specific reason and an appropriate storage plan.
- Review the original paper's full bibliographic details before adding a formal citation.
